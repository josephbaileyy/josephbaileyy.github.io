    How this is built

    Each concept has three separate similarity scores to every other concept, each in [0, 1] with self-similarity 1:

    • Structure (the default map): cosine of relation profiles built from typed links (prerequisite, used in proof, generalizes, implies…). Every link was checked against the Dembo statements and proofs by an independent reviewer agent; an unchecked link would count at half weight.
    • Language: TF-IDF cosine over the sentences of the lecture notes that mention each concept (the agent summary for concepts the notes do not cover yet). It measures shared vocabulary only.
    • Syllabus: closeness in the Dembo reading order, the lecture-note order, syllabus weeks and homework chapters. It is not a prerequisite.

    Each channel is divided by its typical strongest-neighbour similarity, so equal weights give a concept's closest links equal pull in every channel. PCA is kernel PCA of the weighted kernel; Force is a seeded spring–repulsion layout constrained to the sphere; Hybrid starts the force layout from PCA. Each relation lists the source that supports it and whether an independent reviewer agent, which read the Dembo statements and proofs, confirmed it.
