1.1 · PROBABILITY SPACES, MEASURES AND σ-ALGEBRAS

1.1.1   The probability space

The sample space $\Omega$ contains outcomes $\omega$. Its power set $2^\Omega$ contains all subsets. The event space $\mathcal F\subseteq2^\Omega$ specifies which subsets may receive probabilities. We begin with the structure required of $\mathcal F$.
