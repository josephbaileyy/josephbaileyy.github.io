# Authoritative course notes

`230anotes.pdf` is the supplied Amir Dembo, *Probability Theory: STAT310/MATH230*,
April 23, 2019 edition (386 pages). The split reader uses this file unchanged;
entry page numbers are one-based PDF page numbers.

The original course material is separate from this project's companion text and
code. The canonical repository remains private; the reader is also published at
josephrbailey.com/probability/ at the owner's request. Rights to the course notes
remain with their author. This project does not grant a license to redistribute
the PDF.
